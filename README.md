# Gemina

**Research / Architecture Draft** · Architecture Draft v0.1 · 2026-11-02

Mobile Neural Agents in a Shared Trainable Weight Field.

Gemina исследует взаимодействие компактного подвижного нейронного агента с пространством обучаемых весов, координаты которого фиксированы. Предполагается, что предсказательная способность может формироваться совместно в поле и агенте, а навигация — выполнять часть функций контекстного выбора. Это исследовательская гипотеза, не установленный результат.

Самостоятельный проект [LL1yt/Gemina_project](https://github.com/LL1yt/Gemina_project), не ветка Logos Seed. Целевая среда будущей реализации: macOS, Swift, MLX. Здесь только исследовательские документы: **реализация, сборка, обучение, генерация и CI — NOT_RUN**.
