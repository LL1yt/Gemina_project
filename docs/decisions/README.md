## Организационное решение 2026-11-03

Владелец выбрал открытое исследование без обещаний признания, новизны или успеха. Собственный код — MIT; оригинальная исследовательская документация — CC BY 4.0 с исключениями для сторонних материалов. Владелец сохраняет выбор сотрудничества и полномочия принимать изменения. Публичность не предоставляет write access. Цель защиты main: только PR, без force push/удаления/обхода администраторами, без обязательного второго одобрения или несуществующего CI. Решение разрешает настройку только Gemina и не разрешает реализацию, обучение или автоматический merge существующих PR. Выполнение настроек проверяется отдельно: [отчёт](../OPEN-RESEARCH-PUBLICATION.md).

Этот реестр описывает исходный слой main: последующие уточнения и их основания сохранены в [PR #2](https://github.com/LL1yt/Gemina_project/pull/2) и [PR #5](https://github.com/LL1yt/Gemina_project/pull/5), без их автоматического включения. Публикационное оформление не принимает точные предлагаемые формулы и численные настройки и не отменяет записанные в тех ветках указания пользователя.

## Направление MVP и конкретный паспорт M0 — 2026-11-04

Владелец закрепил [трёхуровневый MVP Baseline v0.1](../MVP-BASELINE-v0.1.md): 1) работающее ядро, 2) проверки гипотез, 3) расширения. Отдельный [M0 Implementation Passport v0.1](../M0-IMPLEMENTATION-PASSPORT-v0.1.md) согласует архитектурные выборы свободной абсолютной адресации PR #2 и конкретный первый engineering default из PR #5, включая инициализацию, обучение и минимальную диагностику R1. Паспорт выбирает **исходный воспроизводимый вариант**, а не доказанный оптимум и не разрешение на реализацию. Старый bounded-step — исторический кандидат/будущий контроль. Исходные PR остаются независимыми Draft и не сливаются автоматически. Согласованная стратегия независимой проверки coding-агентов — отдельный [необязательный протокол](../proposals/2026-11-04-INDEPENDENT-BLIND-AGENT-EVALUATION.md), не часть модели.
