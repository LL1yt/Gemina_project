# Исходные решения и их статус

Основание — [миссия v0.2](../../sources/GEMINA-Research-Mission-v0.2.md), разделы 3–5; организационная граница — прямой запрос пользователя 2026-11-02. Этот реестр не принимает предложения Architecture Draft задним числом.

| Положение | Статус и граница |
|---|---|
| Отдельный приватный LL1yt/Gemina_project | Прямое поручение пользователя; не ветка Logos Seed |
| Research / Architecture Draft, без реализации/обучения | Текущая согласованная область работы |
| Трёхмерный тор 16×16×16 | Исходное решение миссии для первого прототипа |
| 32 числа на узел, 131 072 параметра поля | Миссия прямо сохраняет пометку «начальная гипотеза» для 32 |
| Один GRU-агент Lion | Исходное решение миссии |
| Непрерывная адресация и дифференцируемая пространственная интерполяция | Исходное решение; конкретный трилинейный sampler предложен черновиком |
| Авторегрессионное предсказание следующего токена | Исходное решение миссии |
| Общая ошибка обновляет агента и W | Исходный механизм; конкретный optimizer design предложен |
| Swift + MLX, macOS | Целевая среда, не подтверждённая здесь сборка |
| Inference без изменения весов | Граница первой версии; прямая запись/online learning отложены |
| Более медленное W | Предпочтительная начальная гипотеза, не доказанное разделение функций |

Architecture Draft v0.1 остаётся **DRAFT**. Отдельных ADR принятия кандидатного цикла, подробного плана или запуска нет. [Предложения](../proposals/README.md) не считаются принятыми на основании размещения в main.
