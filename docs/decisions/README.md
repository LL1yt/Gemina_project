# Исходные решения и их статус

Основание — [миссия v0.2](../../sources/GEMINA-Research-Mission-v0.2.md), разделы 3–5; организационная граница — прямой запрос пользователя 2026-11-02. Этот реестр не принимает предложения Architecture Draft задним числом.

| Положение | Статус и граница |
|---|---|
| Отдельный приватный LL1yt/Gemina_project | Прямое поручение пользователя; не ветка Logos Seed |
| Research / Architecture Draft, без реализации/обучения | Текущая согласованная область работы |
| Трёхмерный тор 16×16×16 | Исходное решение миссии для первого прототипа |
| 32 числа на узел, 131 072 параметра поля | Миссия прямо сохраняет пометку «начальная гипотеза» для 32 |
| Один GRU-агент Lion | Исходное решение миссии |
| Непрерывная адресация и дифференцируемая пространственная интерполяция | Исходное решение; конкретный трилинейный sampler предложен черновиком |
| Авторегрессионное предсказание следующего токена | Исходное решение миссии |
| Общая ошибка обновляет агента и W | Исходный механизм; конкретный optimizer design предложен |
| Swift + MLX, macOS | Целевая среда, не подтверждённая здесь сборка |
| Inference без изменения весов | Граница первой версии; прямая запись/online learning отложены |
| Более медленное W | Предпочтительная начальная гипотеза, не доказанное разделение функций |

## Уточнения выбора пользователем (2026-11-02; оформлены в Draft PR)

| Положение | Статус и граница |
|---|---|
| В первом будущем прототипе использовать свободную непрерывную **абсолютную** адресацию на каждом токене, вместо ограниченного шага 0.5 | Явное решение пользователя о направлении. Формула навигатора ещё не утверждена; локальный шаг остаётся сравнением |
| Для будущей памяти индексировать одно событие по **восьми узлам с весами интерполяции** | Явный выбор схемы адресации будущей памяти; память после положительного базового опыта |
| Внешние токены также обновляют h/p/r; собственные токены используются как следующий вход при генерации, а не во время подачи prompt | Уточнение вычислительного режима пользователя |
| Прямое вычисление абсолютной координаты и **одно новое чтение на входной токен** | Прямое последующее подтверждение пользователя; конкретная координатная функция не выбрана |
| Локальное кредитование вместо BPTT, повышенный LR, Eagle, rewind и online/sleep learning | **Не приняты как параметры MVP**: будущие проверки и гипотезы |
| Предварительная интенсивная подготовка и последующее переобучение после потери доступного навыка | Уточнённая проверяемая гипотеза, не результат Gemina; не путать с высоким LR как таковым |
| Связная генерация как первый наблюдаемый результат, а польза W/маршрута — отдельные ступени | Согласованное различение цели демонстрации и доказательств участия поля |

Подробное [основание и границы](../proposals/2026-11-02-ARCHITECTURE-CLARIFICATIONS.md). Исходные DOCX и миссия не переписаны; конкретный detailed plan/запуск не разрешены.
