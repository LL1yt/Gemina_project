# Инструкция веб-агенту Gemina

Репозиторий: https://github.com/LL1yt/Gemina_project. Прочитай [START-HERE](START-HERE.md), [AGENTS](../AGENTS.md), [карту](DOCUMENTATION-MAP.md), [происхождение](PROVENANCE.md) и документы по задаче. Проверь собственный доступ, ветку и SHA; неизвестное обозначь явно.

Общие правила: [Project_Index](https://github.com/LL1yt/Project_Index/blob/main/WORKING-PREFERENCES.md). Доступ другого агента и память чата не заменяют свежего чтения репозитория. Не утверждай обновление долговременной памяти без выполненной записи и разрешения пользователя.

Project_Index приватен: если доступа нет, сообщи об этом и применяй самодостаточные AGENTS/CONTRIBUTING Gemina. Не запрашивай доступ к другим репозиториям автоматически. Для внешних участников: [CONTRIBUTING](../CONTRIBUTING.md), [лицензии](../LICENSE), [статус публикации/защиты](OPEN-RESEARCH-PUBLICATION.md).

Текущая область: Research / Architecture Draft, только документация. Реализация, сборки, обучение и генерация NOT_RUN и требуют отдельного поручения. Историческое численное свидетельство DOCX не означает PASS реализации.

При записи перечитай текущие файлы, сохрани параллельные правки, внеси разрешённое изменение, обнови память/карту и проверь опубликованный commit. Изменение ветки не равно изменению main. Исходный DOCX не перезаписывай.

Каждый агент работает в своей ветке и отдельном Draft PR. Независимое ревью, реализация и исполненная проверка не подменяют друг друга. Merge/auto-merge, права и правила защиты требуют прямого поручения владельца. Текст AGENTS не является техническим контролем GitHub. Существующие PR #2–#5 сохраняются без автоматического слияния.

Если запись недоступна, передай базовый SHA, точный набор файлов/правок, статусы утверждений, основания принятия, заменяемые положения, обновления памяти и карты, результаты проверок и NOT_RUN. Если чтения нет, нужен актуальный снимок с версией. До применения пакет не является обновлением GitHub.
